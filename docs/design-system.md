# AgentTerm · 界面设计规范

> 维护人：技术合伙人。本文件只定义「界面长什么样、怎么动」，不涉及进程、PTY、存储等后端逻辑。
> 老板读第 0 节与第 15 节即可；实现细节按需取用。
> 适用范围：桌面版界面（WebView，`src/`）与极简终端版（`agentterm-tui/`，ratatui）。

## 0. 一页速览

| 项         | 结论                                                              |
| ---------- | ----------------------------------------------------------------- |
| 设计目标   | 打开即用；从菜单栏到进入会话最多三次选择；状态一眼可辨            |
| 视觉基调   | 深色（Code dark / Slate）+ 单一「运行绿」强调；无霓虹、无玻璃拟态 |
| 字体       | 系统字体栈（不联网加载字体）                                      |
| 主界面结构 | 顶部标题栏 + 左项目列 + 右会话区（单列退化）                      |
| 状态表达   | 图标 + 文字 + 颜色 三重表达，绝不只靠颜色                         |
| 令牌落地   | CSS 自定义属性（`--at-*`），语义化命名，框架无关                  |
| 明确不做   | 浅色主题实现、动画编排、分屏、主题定制（M2 之后再议）             |

### 当前实现与规范的差距（设计评审依据）

| #   | 现状                                                 | 问题                                                       | 规范位置 |
| --- | ---------------------------------------------------- | ---------------------------------------------------------- | -------- |
| 1   | 首屏 `h1` 用 `clamp(32px, 7vw, 56px)` 的宣传式大标题 | 工具型桌面应用浪费约 30% 首屏高度                          | §6.1     |
| 2   | 顺序为「Hero → 项目 → 工具」三段平铺                 | PRD 场景是「项目 → 工具 → 会话」，工具卡常被挤到折叠线以下 | §2、§6.1 |
| 3   | 「启动」是行内二级操作（先点启动，工具按钮才出现）   | 两步点进，选择态与项目行混排                               | §7.4     |
| 4   | 状态只有文字徽章，部分靠颜色区分                     | 色觉障碍用户无法区分运行/退出                              | §8       |
| 5   | 焦点环用品牌绿 `#00ff41`                             | 绿底按钮上焦点环不可见                                     | §10      |
| 6   | 样式声明 `Inter` 但未加载字库                        | 实际落到系统字体，属隐式依赖                               | §4       |

| 8   | 间距圆角散落（8/10/12px 混用），无常量               | 无法统一维护                                               | §5       |

## 1. 设计原则（每条都可机械核对）

| 原则 | 含义                                                                | 怎么核对                          |
| ---- | ------------------------------------------------------------------- | --------------------------------- |
| P1   | 任一状态下只允许一个主操作（视觉最重的按钮）                        | 每屏截图数一数主色按钮，最多 1 个 |
| P2   | 运行 / 退出 / 缺失 / 不可执行四态必须「图标 + 文字 + 颜色」三重表达 | 灰度截图下仍能分辨各状态          |
| P3   | 从打开应用到进入会话最多三次选择（对齐 PRD 成功标准）               | 走一遍：选项目 → 选工具 → 启动    |
| P4   | 首屏零配置项：不出现偏好设置、主题、快捷键等面板                    | 首屏无「设置」类入口              |
| P5   | 克制的科技感：单一强调色 + 克制的圆角阴影，不做装饰性动效           | 视觉噪声来源不超过 1 处           |

## 2. 界面地图

| 状态       | 触发                    | 画面构成                               | 主操作          |
| ---------- | ----------------------- | -------------------------------------- | --------------- |
| 启动台     | 打开窗口且无运行会话    | 标题栏 + 项目列 + 工具列 + 空态提示    | 选项目并启动    |
| 会话态     | 已有运行中的会话        | 标题栏 + 项目列 + 会话标签栏 + 终端区  | 切换 / 新建会话 |
| 辅：空态   | 未添加任何项目          | 居中说明 + 「添加项目」按钮 + 提示文案 | 添加项目        |
| 辅：错误态 | 启动失败 / 工具不可执行 | 就地错误条（不弹窗、不换屏）           | 重试 / 去处理   |
| 辅：确认态 | 移除项目 / 关闭运行会话 | 就地二次确认条（行内替换按钮）         | 确认 / 取消     |

规则：

- 错误一律**就地显示**，不用模态弹窗打断流程（PRD 场景 3）。
- 确认一律**行内替换**，避免用户丢失上下文（现状的移除确认已符合，保留）。
- 任何状态都不允许「无反应」：每个操作都有可见反馈。

## 3. 视觉基调

### 3.1 采纳与不采纳

| 方向                     | 结论     | 理由                                                     |
| ------------------------ | -------- | -------------------------------------------------------- |
| Dark Mode (OLED) + Slate | 采纳     | 与终端同色系，长时间不刺眼；与 PRD「轻量、克制」一致     |
| 单一「运行绿」作为强调色 | 采纳     | 绿色=可运行，与命令行习惯一致；一色到底避免花哨          |
| Cyberpunk 霓虹 / 扫描线  | 不采纳   | 无障碍仅达 AA 边缘、视觉噪音高，与「克制」冲突           |
| 玻璃拟态 / 模糊          | 不采纳   | WebView 下性能与文字对比度都受损，收益低                 |
| Light 主题               | 暂不实现 | 保留令牌命名以便将来扩展；本轮不产出浅色值，避免范围膨胀 |

### 3.2 颜色令牌（深色主题，已实测对比度）

| --------------------- | --------------------- | ------------------------ | ------------------------------- |

| `--at-surface-raised` | `#1B2336`             | 卡片 / 行                | —                               |
| `--at-surface-sunken` | `#0B1220`             | 终端宿主（凹陷区）       | —                               |
| `--at-surface-hover`  | `#222C42`             | 悬停                     | —                               |
| `--at-surface-active` | `#2A3550`             | 选中 / 按下              | —                               |
| `--at-border-subtle`  | `#223049`             | 分隔线、卡片描边         | —                               |

| `--at-border-strong`  | `#475569`             | 悬停描边                 | —                               |
| `--at-text-primary`   | `#F8FAFC`             | 标题、正文               | 17.06:1（app）/ 14.98:1（card） |
| `--at-text-secondary` | `#A8B6CC`             | 次要说明                 | 8.70:1 / 7.63:1                 |
| `--at-text-tertiary`  | `#7E8CA5`             | 路径、版本号             | 5.26:1 / 4.61:1                 |
| `--at-accent`         | `#22C55E`             | 主按钮、运行中           | 7.83:1 / 6.88:1                 |
| `--at-accent-hover`   | `#34D06A`             | 主按钮悬停               | —                               |
| `--at-accent-quiet`   | `rgba(34,197,94,.14)` | 运行中状态底色           | —                               |
| `--at-on-accent`      | `#06180D`             | 主按钮上的文字           | 8.05:1（对 accent）             |

| `--at-status-running` | `#22C55E`             | 运行中                   | 7.83:1                          |
| `--at-status-idle`    | `#94A3B8`             | 已退出 / 空闲            | 6.96:1 / 6.11:1                 |
| `--at-status-missing` | `#94A3B8`             | 工具未安装（配图标区分） | 6.96:1 / 6.11:1                 |
| `--at-status-warning` | `#FB923C`             | 不可执行 / 有风险        | 7.89:1 / 6.92:1                 |
| `--at-status-error`   | `#F87171`             | 启动失败 / 错误文案      | 6.45:1 / 5.66:1                 |

约束：

- 颜色**不得单独**承担语义，必须搭配图标与文字（P2）。
- 错误文案在卡片底色上必须 ≥4.5:1，故用 `#F87171` 而非 `#EF4444`（后者在卡片上仅 4.16:1）。
- 主按钮用深色文字（`--at-on-accent`）；若将来改浅色按钮，需重新计算。
- 焦点环 `#38BDF8` 始终**落在深色背景上**（2px 偏移），因此不与绿色主按钮冲突。

## 4. 字体与排版

### 4.1 字体栈（不加载网络字体）

| 用途 | 栈                                                                                            |
| ---- | --------------------------------------------------------------------------------------------- |
| 界面 | `-apple-system, BlinkMacSystemFont, "Segoe UI Variable Text", "Segoe UI", Inter, sans-serif`  |
| 等宽 | `"SFMono-Regular", "Cascadia Code", "JetBrains Mono", Consolas, "Liberation Mono", monospace` |

规则：

- 桌面应用不联网加载 webfont：字体缺失会导致首屏闪动与体积膨胀，且系统字体更贴合平台观感。
- 等宽字体**只**用于路径、版本号、命令、技术标识；不用于正文。
- 现状 CSS 声明了 `Inter` 却未引入字库，属隐式依赖，本规范以系统栈为准（§0 差距 #6）。

### 4.2 字号阶梯

| 级别       | 字号 / 行高 | 字重 | 用途                                   |
| ---------- | ----------- | ---- | -------------------------------------- |
| `display`  | 28 / 36     | 650  | 窗口标题区主标题（不再使用 56px 巨幅） |
| `title-lg` | 20 / 28     | 650  | 区块标题                               |
| `title-md` | 16 / 24     | 600  | 卡片标题、标签页标题                   |
| `body`     | 14 / 21     | 400  | 正文、按钮文字                         |
| `body-sm`  | 13 / 20     | 400  | 次要说明、状态描述                     |
| `label`    | 12 / 16     | 550  | 标签、状态芯片、时间戳                 |
| `mono-sm`  | 12 / 18     | 400  | 路径、版本号（等宽）                   |

规则：

- 正文不小于 13px；工具型桌面应用可用 13–14px（移动端 16px 规则不适用）。
- 标题字重只到 650，避免与正文争抢层级。
- 单行文本超长一律省略号截断并提供 `title` 悬停全文（路径类必须）。

## 5. 间距、圆角、层级、动效

### 5.1 间距（4px 栅格）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

| 场景         | 值    |
| ------------ | ----- |
| 图标与文字   | 6–8   |
| 卡片内边距   | 16    |
| 卡片之间     | 12    |
| 区块之间     | 24–32 |
| 窗口内边距   | 24    |
| 页面左右留白 | 24–32 |

### 5.2 圆角

| 令牌               | 值    | 用途           |
| ------------------ | ----- | -------------- |
| `--at-radius-sm`   | 6px   | 状态芯片、徽章 |
| `--at-radius-md`   | 8px   | 按钮、输入框   |
| `--at-radius-lg`   | 12px  | 卡片、终端宿主 |
| `--at-radius-pill` | 999px | 胶囊标签       |

### 5.3 层级

| 级别 | 表现                                                    |
| ---- | ------------------------------------------------------- |
| 0    | 背景层                                                  |
| 1    | 卡片：描边 `#223049` + 背景 `#1B2336`，**不用阴影**     |
| 2    | 浮层（菜单、提示）：`0 12px 32px -8px rgba(2,6,23,.55)` |
| 3    | 终端宿主：凹陷背景 `#0B1220` + 内描边                   |

### 5.4 动效

| 令牌               | 时长  | 曲线                       | 用途            |
| ------------------ | ----- | -------------------------- | --------------- |
| `--at-motion-fast` | 120ms | `ease-out`                 | hover / 按下    |
| `--at-motion-base` | 180ms | `cubic-bezier(.16,1,.3,1)` | 展开 / 标签切换 |
| `--at-motion-slow` | 260ms | `cubic-bezier(.16,1,.3,1)` | 面板出现        |

规则：

- 只动 `transform` 与 `opacity`，不动宽高，避免布局抖动。
- 退场时长取进入的 70%（更利落）。
- 必须支持 `prefers-reduced-motion: reduce`（现状已有，保留）。
- 装饰性动效一律不做（P5）。

## 6. 布局骨架

### 6.1 启动台（桌面版默认态）

```text
┌──────────────────────────────────────────────────────────────┐
│ ▚ AgentTerm                                    [重新检测] ●   │  标题栏 56px
├───────────────────────────────┬──────────────────────────────┤
│ 项目                     [+]  │ 工具                          │
│ ┌───────────────────────────┐ │ ┌──────────┐ ┌──────────┐    │
│ │ AgentTerm        ● 就绪   │ │ │ Claude   │ │ Codex    │    │
│ │ ~/AgentTerm               │ │ │ Code     │ │ v1.2.3   │    │
│ │                    [启动▾]│ │ │ v2.1.318 │ │          │    │
│ └───────────────────────────┘ │ │   [启动]  │ │  [启动]  │    │
│ ┌───────────────────────────┐ │ └──────────┘ └──────────┘    │
│ │ dsh-superagent      ● 就绪 │ │ ┌──────────┐                  │
│ │ ~/src/dsh-superagent      │ │ │ Agy      │                  │
│ │                    [启动▾]│ │ │ 未安装   │                  │
│ └───────────────────────────┘ │ │  [安装?] │                  │
│                               │ └──────────┘                  │
├───────────────────────────────┴──────────────────────────────┤
│ 提示条：未添加项目时显示「添加项目」按钮                      │
└──────────────────────────────────────────────────────────────┘
```

要点：

- 项目与工具是**两个并列维度**，不是三段平铺；工具区在右侧常驻可见，不再沉底。
- 每个项目行只有一个主按钮「启动」；点击后展开工具选项（就地），不跳屏。
- 标题栏右侧常驻「重新检测」与一个整体状态点（全部工具是否可用）。

### 6.2 会话态

```text
┌──────────────────────────────────────────────────────────────┐
│ ▚ AgentTerm                                    [新建会话] ●   │
├──────────────┬───────────────────────────────────────────────┤
│ 项目         │ [AgentTerm · Claude Code ● 运行中][Codex ○ 已退出]│
│ ▸ AgentTerm  │───────────────────────────────────────────────│
│   dsh-super  │                                               │
│               │  终端区（--at-surface-sunken，内嵌 xterm）     │
│               │                                               │
│               │                                               │
├──────────────┴───────────────────────────────────────────────┤
│ 状态栏：会话标题 / 工作目录 / 运行时长 / [关闭会话]           │
└──────────────────────────────────────────────────────────────┘
```

要点：

- 标签栏固定在终端上方，标签显示「项目 · 工具 + 状态点」，不靠颜色单独区分。
- 关闭运行中的会话：标签上先出现行内确认条，不弹窗。
- 终端区不显示任何装饰边框以外的重装饰，输出可读性第一。

### 6.3 空态与错误态

```text
空态：                                  错误（就地）：
┌──────────────────────────────┐        ┌──────────────────────────────┐
│                              │        │ ! Claude Code 启动失败        │
│      还没有项目              │        │   找不到可执行文件 claude     │
│   添加一个本地文件夹，        │        │   [重试]  [查看路径]           │
│   就能开始用 AI 工具干活。     │        └──────────────────────────────┘
│      [ 添加项目 ]             │
└──────────────────────────────┘
```

## 7. 组件规范

### 7.1 按钮

| 变体     | 用法              | 外观                                                        | 尺寸            |
| -------- | ----------------- | ----------------------------------------------------------- | --------------- |
| 主按钮   | 每屏唯一          | 底 `--at-accent`，字 `--at-on-accent`                       | 高 36px         |
| 次按钮   | 辅助动作          | 透明底 + 描边 `--at-border-default`，字 `--at-text-primary` | 高 36px         |
| 幽灵按钮 | 三级/取消         | 无底无描边，hover 出 `--at-surface-hover`                   | 高 32px         |
| 危险按钮 | 移除/关闭运行会话 | 描边与字 `--at-danger`，底透明                              | 高 32–36px      |
| 图标按钮 | 工具栏            | 无底，图标 16px，需 `aria-label`                            | 命中区 ≥28×28px |

规则：

- 禁用态：透明度 0.5 + `cursor: not-allowed` + `aria-disabled`。
- 加载态：按钮禁用 + 文案变为进行中（不换图标避免布局跳动）。
- 命中区：桌面端最小 28×28px（触控 44px 规则面向移动端，此处放宽但不得更小）。

### 7.2 状态芯片（Status chip）

```text
● 运行中     ○ 已退出     ! 不可执行     – 未安装     ✕ 失败
```

| 状态     | 图标       | 颜色令牌              | 文案     |
| -------- | ---------- | --------------------- | -------- |
| 运行中   | 实心圆点   | `--at-status-running` | 运行中   |
| 已退出   | 空心圆     | `--at-status-idle`    | 已退出   |
| 不可执行 | 三角感叹号 | `--at-status-warning` | 不可执行 |
| 未安装   | 短横       | `--at-status-missing` | 未安装   |
| 失败     | 叉号       | `--at-status-error`   | 启动失败 |

规则：图标 12px 跟随文字基线；芯片为 `--at-radius-pill`；底色仅运行中使用 `--at-accent-quiet`。

### 7.3 工具卡

- 卡片标题=工具名（`title-md`）；版本号用 `mono-sm` + `--at-text-tertiary`。
- 路径用 `mono-sm` 截断显示，悬停出完整路径，点击可复制。
- 状态芯片在标题右侧；「启动」按钮在卡片底部右对齐。
- 未安装的工具：标题置灰 + 说明「未检测到 claude」+ 次按钮「查看安装说明」（外链或文案）。

### 7.4 项目行 / 工具选择

- 项目行=名称（`title-md`）+ 路径（`mono-sm`）+ 状态芯片 + 「启动」主按钮。
- 点击「启动」后**就地展开**工具选项（按钮组 + 取消），不弹窗、不换屏。
- 展开期间不改变行高以外的布局；同一时刻只允许一行处于展开态。
- 移除项目走行内确认条：「只移除记录，不删除文件夹。」+「确认移除」「取消」。

### 7.5 会话标签

- 标签 = 项目名 · 工具名 + 状态点；活动标签用 `--at-surface-active` 底色 + 顶部 2px 强调线。
- 关闭按钮 hover 才出现（避免误点），但键盘聚焦时必须可见。
- 运行中的会话关闭时出现行内确认：「该会话仍在运行，关闭会中断它。」

### 7.6 错误条 / 确认条

- 错误条：左侧图标 + 原因 + 下一步按钮；就地位于出错对象下方，`role="alert"`。
- 确认条：替换原按钮区域，不叠加，避免布局跳动。

### 7.7 空态

- 居中（最大宽度 360px），一句说明 + 一个主按钮；不插画、不 emoji。
- 文案给下一步动作，不描述功能。

## 8. 状态语义表

| 场景         | 判定         | 界面表达                        | 用户可做什么        |
| ------------ | ------------ | ------------------------------- | ------------------- |
| 工具已安装   | 可执行       | 名称 + 版本 + 绿点「就绪」      | 启动                |
| 工具未安装   | 找不到二进制 | 灰点「未安装」+ 原因（PATH 缺） | 看安装说明          |
| 工具不可执行 | 存在但无权限 | 橙点「不可执行」+ 权限原因      | 修权限后重试        |
| 启动失败     | PTY 启动异常 | 红点 + 就地错误条 + 原因        | 重试                |
| 会话运行中   | PTY 存活     | 绿点「运行中」+ 计时            | 切换 / 关闭（确认） |
| 会话已退出   | 进程结束     | 灰点「已退出」+ 退出原因        | 关闭 / 重开         |
| 项目路径失效 | 目录不存在   | 行内提示「目录已不存在」        | 重新选择 / 移除     |

## 9. 图标与文案规范

### 9.1 图标

- 统一使用一套 SVG 图标（Lucide 风格），线宽 1.5px，端点圆角。
- 尺寸两档：16px（行内/标签）、20px（工具卡/标题栏）；图标按钮命中区 ≥28px。
- 禁止用 emoji 当结构图标；禁止混用多套图标风格。
- 状态图标（圆点/叉/三角）单独成套，不与功能图标混用。

### 9.2 文案

- 中文短句，动词开头，不写技术黑话给老板看；错误文案 = **原因 + 怎么办**。
- 同一动作全应用同名（「添加项目」「移除」「启动」「关闭会话」），不混用「删除/清除」。
- 不使用「确定吗？」这类无信息文案，直接写清后果：「关闭会中断正在运行的会话」。
- 数字与时间统一格式：路径原样、版本 `v2.1.318`、时长 `12 分 03 秒`。

## 10. 无障碍与键盘

| 项       | 要求                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 对比度   | 正文 ≥4.5:1，大字/图形 ≥3:1（§3.2 已实测）                              |
| 焦点可见 | 2px `--at-focus-ring` + 2px 偏移，落在深色背景上；不得移除              |
| 焦点顺序 | 与视觉顺序一致：标题栏 → 项目列 → 工具列 → 会话区 → 状态栏              |
| 键盘可达 | 全流程可用键盘完成：Tab 移动、Enter 触发、Esc 取消展开/返回项目列       |
| 语义     | 标题层级连续（h1 → h2），图标按钮带 `aria-label`，错误用 `role="alert"` |
| 状态播报 | 会话状态变化用 `aria-live="polite"` 播报                                |
| 动态文字 | 系统字号放大 200% 时不截断关键信息、不重叠                              |
| 减弱动效 | `prefers-reduced-motion: reduce` 下全部动效归零（现状已实现）           |
| 不靠颜色 | 灰度截图可分辨全部状态                                                  |

## 11. 窗口尺寸与响应式

窗口实测参数（`src-tauri/tauri.conf.json`）：默认 1100×720，最小 720×520。

| 断点 | 宽度   | 布局                                             |
| ---- | ------ | ------------------------------------------------ |
| 窄   | < 900  | 单列：项目在上、工具在下（工具不折叠，但可横滑） |
| 标准 | ≥ 900  | 双列：项目列 320px + 工具/会话区自适应           |
| 宽   | ≥ 1280 | 双列 + 项目列 360px，会话区最大内容宽度不封死    |

规则：

- 最小窗口 720×520 下，所有操作仍可达（不出现横向滚动条）。
- 终端区最小高度 320px；低于此高度时优先压缩标题区。
- 不用固定像素容器宽度；用 `minmax()` 与 `fr` 分配。
