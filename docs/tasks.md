## 已知边界

- rc.13 终端输入异常的三项缺陷已在 rc.14 候选修复并通过定向回归，完整质量门与安装待验。
  已进入系统调用的写入无法撤回，超时后封锁会话输入，需检查输出后结束会话再重开。
- 当前只接受本应用创建的本地 PTY，不接管外部终端中的既有会话。
- 定时任务在 Windows 只直接启动 `.exe`，拒绝批处理和 PowerShell 包装。
- 首次安装和安装包更新仍可能触发系统安全提示；代码签名与公证未完成，
  这是 `0.2.0` 正式发布前的阻断项（见 [发布说明](release-signing.md)）。
- rc.7 及更早（无待确认字段）与 rc.8（带待确认字段）的定时任务记录可直接读取；
  旧版本创建的错误任务不会自动改写，需要在新面板中删除后重建。
